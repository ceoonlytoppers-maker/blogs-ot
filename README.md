# OnlyToppers Journal (blog.onlytoppers.com)

Eleventy static blog. Add posts as Markdown files in `src/posts/`.

- Local preview: `npm install` then `npm start`
- Build: `npm run build` (output in `_site/`)
- Netlify: build command `npx @11ty/eleventy`, publish directory `_site`
- Optional CMS: `/admin/` (Decap CMS). Set `repo` and `base_url` in `src/admin/config.yml`.
